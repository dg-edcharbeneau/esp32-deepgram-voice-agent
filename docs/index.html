Not a render

This is the actual board.

A 466 × 466 round AMOLED, unmodified and out of the box. The orb is drawn on-device at ~25 frames a second, its behaviour driven by the session state — connecting, thinking, speaking, idle.

Tools wired to its own hardware

Ask it to change, and it changes.

Not settings. The agent holds tools that reach the codec, the display and the session, so the way you reconfigure this device is to mention it out loud.

“Turn it down a bit.”

One ES8311 register write. Deepgram never learns the volume, so nothing reloads.

“Call yourself Ada.”

Saved to flash and folded into the system prompt as its own name.

“Show me the spectrum.”

Swaps the face: 24 bands mirrored into 48 bars, bass at twelve o'clock.

“Make the orb mint.”

Re-inks 456 dots at the single point where colour becomes pixels.

“Use a different voice.”

Reopens the session with the new voice and replays the history, because the in-place update is silently ignored upstream.

“Goodbye.”

Ends the turn. Nobody talking for a while and it sleeps on its own.

One line per second, over serial

It tells you what it is doing.

Every counter here splits a failure in half. Audio arriving but not playing is a codec problem; audio playing but no reply is a capture problem. You never have to guess which half broke.

TLM up=6.1 face=orb beh=SPEAKING src=agent sess=ready frames=25 fps=25.0
    draw=17.8/22.1 amp=0.417/0.592 low=0.34/0.49 mid=0.36/0.56 high=0.23/0.35
    turns=1 mic=38400 rx=107520 played=107520 drop=0 heap=5917691

Captured from a board mid-sentence. played matching rx with drop=0 is a healthy turn.

Three steps, no toolchain

Get one running.

The published image carries no API key and no network, so it comes up asking for both.

Download the image

One file: bootloader, partition table and app together, so flashing needs to know nothing about the layout.

Write it to the board

With esptool and the board in download mode.

esptool.py -c esp32s3 -p /dev/YOUR-PORT \ write_flash 0x0 deepgram_agent-merged.bin

Scan the QR on the panel

It raises its own encrypted access point and shows the code. Your phone joins, a page asks for your network and your Deepgram API key, and it reboots talking.
